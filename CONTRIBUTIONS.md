# Contributions

Who led what, with links to the evidence. Each member fills in their own row and their own file in `contributions/` **after** their work is merged. Every link should point to something on GitHub, so anyone can check it.

`CONTRIBUTIONS_LOG.md` is generated from the git history by `tools/contribution_report.py` and lists every commit by author.

**Baseline.** The first commit (message starting with `Baseline`) is the shared starting draft of the full analysis, prepared with AI assistance. It is not counted as anyone's stage work. Everything after it is recorded per person.
